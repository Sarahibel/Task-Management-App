Reflection:

1- Challenges faced during the project?
=> Challenges I faced
One thing I had to figure out was when to show a task as overdue. I wanted tasks due today to still show as In Progress. I also had to make sure the category and status filters worked together.

2- How you approached solving those challenges?
=>How I solved them
I made a function to check the task’s deadline and status. I used that same function when showing the tasks and when filtering them. To check that it worked, I tested three tasks with deadlines for yesterday, today, and tomorrow. I also marked the overdue task as complete and refreshed the page to see if it stayed completed.

3- What you would improve if given more time?
=>What I would improve with more time
I would add a warning when a task’s deadline is coming up so users have time to finish it. I would also add a way to edit and delete tasks. For example, if I entered the wrong deadline, I’d want to be able to fix it after adding the task.
